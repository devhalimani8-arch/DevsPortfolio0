# Dev Mahesh Halimani – Portfolio Website

A personal digital portfolio built with HTML, CSS, and JavaScript for the MITVPU Module 5 Project Presentation assignment.

## 🌐 Live Site
Deploy via GitHub Pages from the `main` branch (root folder).

## 📁 File Structure
```
portfolio/
├── index.html        ← Main HTML file
├── style.css         ← All styles + dark mode
├── script.js         ← Interactions, animations
├── README.md
└── assets/
    ├── photo1.jpeg       ← Profile photo 1
    ├── photo2.jpeg       ← Profile photo 2
    ├── cert-cisco.jpeg   ← Cisco Networking Academy certificate
    └── cert-coursera.jpeg ← Coursera / IESE certificate
```

## ✅ Sections Included
- **Home** – Photo, name, tagline, hero badges
- **About Me** – Education, interests, goals, strengths
- **Achievements** – Cisco AI, Coursera Org Behavior, YuvaAI, Design Thinking
- **Projects** – Watch Store (live link), Ai4A, Design Thinking, Marketing Case Study
- **Gallery** – All photos and certificates
- **Contact** – Email, phone, LinkedIn, GitHub + contact form

## ⭐ Extra Features
- 🌙 Dark Mode Toggle (persists via localStorage)
- ✨ Scroll reveal animations
- 🔍 Image lightbox viewer
- ⌨️ Typing animation on hero tagline
- 📱 Fully responsive / mobile menu

## 🚀 How to Deploy on GitHub Pages
1. Create a new GitHub repository (e.g., `portfolio`)
2. Upload all files maintaining the folder structure
3. Go to **Settings → Pages**
4. Set source to `main` branch, root `/`
5. Save — your site will be live at `https://yourusername.github.io/portfolio`
